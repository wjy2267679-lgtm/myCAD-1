# 六棱台与三棱柱相贯 — 三投影补全与 3D 模型

对应题目：**立体截切、相交综合测试（四）第 1 题 —— 完成六棱台与三棱柱相贯线的三投影。**

## 立体参数

| 对象 | 参数 |
|---|---|
| 六棱台 | 底面正六边形 R=44，顶面 r=18，高 H=48；左右为顶点、前后为平边 |
| 三棱柱 | 截面倒三角 ▽：顶边 z=26（宽 24），下顶点 z=8；沿前后方向 y∈[−42, 42] 贯穿并两端伸出 |

棱台前/后侧面所在平面：`y = ±(38.1051 − 0.46910·z)`。

## 相贯线

三棱柱的 x 范围 [−12, 12] 只覆盖棱台的前、后两个侧面（相邻侧面 x≥22），因此相贯线是
**前后各一个空间三角形**，由三段直线组成：

| 棱柱棱线 | 后侧交点 (x, y, z) | 前侧交点 |
|---|---|---|
| 左上棱 | (−12, 25.9086, 26) | (−12, −25.9086, 26) |
| 右上棱 | (12, 25.9086, 26) | (12, −25.9086, 26) |
| 下棱 | (0, 34.3523, 8) | (0, −34.3523, 8) |

校核：棱台侧面在 z=26、z=8 处的 x 半宽为 14.96、19.83，均大于 12，故棱柱截面完整落在该侧面内；
棱台最大 y（z=8 处）为 34.35 < 42，故棱柱确实两端穿出。

## 三投影补全要点

- **主视图（V）**：相贯线积聚在已画的倒三角形上，无需新增线。
- **俯视图（H）**：补前后两个三角形，均为虚线（被棱台顶面遮挡），底边 y=±25.9086 跨 x∈[−12,12]，顶点 (0, ±34.3523)。
- **左视图（W）**：整体补画；相贯线积聚在棱台左右斜轮廓线 z∈[8,26] 的两段上。棱柱轮廓在棱台外为实线、棱台内为虚线。

## 文件

| 文件 | 说明 |
|---|---|
| `model_3d.html` | **可旋转、可缩放的交互式 3D 模型**（单文件，零外部依赖，浏览器直接打开） |
| `three_views.svg` / `.png` | 补全后的三视图 |
| `iso.svg` / `.png` | 轴测图 |
| `model.stl` | 3D 模型（36 三角面，三个实体均为闭合流形） |
| `solve.py` | 参数化求解：几何、相贯线、SVG、STL |
| `render.py` | 纯标准库光栅化器（SVG→PNG，无第三方依赖） |
| `export_html.py` | 导出交互式网页 |

## 交互操作

左键拖拽旋转 · 滚轮 / 双指捏合缩放（0.8–22×）· 右键拖拽平移 · 复位视角
· 可切换「相贯线 / 棱线 / 三棱柱 / 自动旋转」。关闭「显示三棱柱」即可看到棱台表面上完整的红色相贯三角形。

## 重新生成

```bash
python3 solve.py        # 相贯线 + three_views.svg + iso.svg + model.stl
python3 render.py       # three_views.png + iso.png
python3 export_html.py  # model_3d.html
```

仅依赖 Python 标准库。
